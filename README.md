# Wikisource Toolkit

Инструменты на TypeScript для сверки OCR со сканами, проверки включений ProofreadPage и пакетной публикации викитекста. Рабочие сценарии выросли из проекта первой редакции Большой советской энциклопедии в русской Викитеке. [English overview](README.en.md)

## Попробовать локально

Понадобится [Bun](https://bun.sh/). Проект проверен на Bun 1.3.10 и использует встроенные библиотеки Bun и Node.js.

```sh
bun run demo
bun test
```

Демонстрация поднимает локальный имитатор MediaWiki и создаёт результаты в `.demo/`. Откройте `.demo/review/index.html` в браузере или [скачайте готовый HTML-отчёт](https://github.com/programmcompose/wikisource-toolkit/releases/download/v0.1.0/review-demo.html). На первой странице видно различие OCR и исправленного текста. Статья «Река» проходит проверку через две страницы, «Озеро» задерживается из-за закрывающего тега `озеро42`, «Мост» пропускается как существующий.

| Результат | Где открыть |
|---|---|
| Скан, предпросмотр текста и расхождения OCR | `.demo/review/index.html` |
| Причина задержки для редактора | `.demo/vols/07/pages-held.md` |
| Результаты проверок для автоматизации | `.demo/vols/07/checks.jsonl` |
| Викитекст и список запланированных страниц | `.demo/vols/07/wiki-pages/`, `.demo/vols/07/manifest-pages.jsonl` |
| Метрики и расхождения с эталоном | `.demo/eval/report.md`, `.demo/eval/diffs.md` |

## Инструменты

| Задача | Команды |
|---|---|
| Сверить скан, исходный OCR и исправленный викитекст | [`pilot.ts`](pipeline/pilot.ts), [`style.ts`](pipeline/style.ts) |
| Проверить границы секций и собрать статьи через `<pages>` | [`prepare.ts`](pipeline/prepare.ts), [`transclude.ts`](pipeline/transclude.ts) |
| Собрать статьи из вручную вычитанных текстов | [`todo.ts`](pipeline/todo.ts), [`build.ts`](pipeline/build.ts) |
| Создать страницы по манифесту или обновить страницы индекса | [`upload.ts`](pipeline/upload.ts), [`pilot-upload.ts`](pipeline/pilot-upload.ts) |
| Внести проверенные точечные замены с diff «до / после» | [`pagefix.ts`](tools/pagefix.ts) |
| Перенести тело статьи на страницы индекса и сохранить включение | [`migrate.ts`](pipeline/migrate.ts) |
| Сравнить OCR и предложенное исправление с эталоном | [`eval.ts`](pipeline/eval.ts), [методика](docs/evaluation.md) |
| Извлечь словники и номера столбцов из OCR | [МСЭ](mse/extract.ts), [ССЭ](sse/extract.ts), [подготовка входных файлов](docs/wordlists.md) |

Начните с [инструкции по работе с Викитекой](docs/workflows.md). Для интеграции используйте [описание файлов и JSON Schema](docs/formats.md). Имена пространств, словник, шаблоны и правила отбора штатного конвейера соответствуют БСЭ1. Для своего издания отдельно адаптируйте эти правила и проверьте рендер в целевой вики.
