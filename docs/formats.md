# Форматы для интеграции

Файлы JSONL используют UTF-8. Каждая непустая строка — отдельный объект JSON. Схемы Draft 2020-12 описывают одну строку, поэтому проверяйте объекты после разделения файла на строки.

| Файл | Содержание |
|---|---|
| `articles.jsonl` | Список статей из `prepare.ts`. `id` устойчив внутри текущего словника тома. `status` принимает `exists`, `blocked`, `review` или `candidate`. [Тип Article](../pipeline/prepare.ts) |
| `pages.json` | Массив снимков страниц `{ "file": "Том.pdf", "n": 42, "content": "…викитекст…" }`. |
| `checks.jsonl` | Итог каждой статьи из `transclude.ts`. [Схема](../schemas/check.schema.json) |
| `manifest.jsonl`, `manifest-pages.jsonl` | Список строк для создания страниц. [Схема](../schemas/manifest.schema.json) |
| `journal.jsonl` | Журнал создания страниц из манифеста. [Схема](../schemas/journal.schema.json) |

## Результаты проверки включений

```jsonl
{"id":"0001","title":"Река","status":"ready","plan":{"index":"Учебный индекс.pdf","from":1,"to":2,"section":"река"}}
{"id":"0002","title":"Озеро","status":"held","code":"section_end_mismatch","message":"нет закрывающего тега с тем же именем"}
{"id":"0003","title":"Мост","status":"skipped","code":"exists"}
```

`ready` означает, что статья прошла проверки локальной разметки и рендера API. `local_pass` означает, что прошла локальная часть проверки. `held` содержит первую причину задержки. `skipped` означает, что статья не попала на проверку. Для автоматизации используйте `status` и `code`, а в интерфейсе показывайте `message`. Номера в `plan` относятся к страницам файла.

## Манифест и журнал

```jsonl
{"title":"Река","page":"БСЭ1/Река","file":"wiki-pages/0001.wiki","summary":"Статья по вычитанным страницам индекса"}
```

`page` — полное название страницы. `file` — путь относительно папки тома. Переносите манифест вместе с указанными в нём файлами и просматривайте оба перед публикацией. Журнал имеет `title`, `result`, `at` и при успешном создании — `revid`. При остановке `response` может содержать возвращённую API причину. Статусы других журналов, например обновления страницы индекса, могут отличаться.

## Заметки к страницам

```json
{
  "42": {
    "why": "Проверить вторую колонку",
    "notes": ["⚠ Проверить: на скане 1934 или 1931?", "В OCR исправлен порядок строк."]
  }
}
```

## Точечные замены

```json
{
  "file": "Учебный индекс.pdf",
  "summary": "Исправлено имя конца секции по словнику",
  "fixes": {
    "2": [["<section end=\"озеро42\"/>", "<section end=\"озеро\"/>", "42 — номер столбца"]]
  }
}
```

Каждая замена задаёт исходную и итоговую строку и необязательное пояснение. Скрипт отслеживает точное совпадение. При сохранении примера как редакционного материала добавьте URL страницы и базовую ревизию в сопроводительной записи.
