# Извлечение словников

Эти команды создают черновики словников с предполагаемыми заголовками и столбцами. Сверьте границы и нумерацию по сканам перед использованием. TSV можно открыть в табличном редакторе или обработать по названиям колонок.

## МСЭ из OCR с координатами

Поместите OCR DjVu XML в `mse/ocr/xml/1-10.xml`, а текстовый слой для построения словаря в `mse/ocr/1-10.txt`. Для других томов смотрите ключи `VOLS` в [`mse/extract.ts`](../mse/extract.ts). Скрипты `mse/tools/get-xml.ts` и `mse/tools/get-ocr.ts` получают доступные текстовые слои из Internet Archive. Можно подготовить входные файлы самостоятельно.

```sh
bun mse/extract.ts 1-10
```

Результаты — `mse/vols/1-10/pages.tsv`, `headwords.tsv`, `report.md` и `mse/drafts/словник-1-10.wiki`. Для сравнения с существующим словником положите его викитекст в `mse/ref/словник-1-10.wiki` и запустите `bun mse/tools/compare.ts 1-10`. Нечёткие совпадения и приблизительные столбцы требуют проверки.

## ССЭ из текстового слоя PDF

Подготовьте текст с сохранённым расположением двух колонок. Для этого подходит инструмент Poppler `pdftotext`.

```sh
pdftotext -layout -enc UTF-8 volume.pdf sse/text/t1.layout.txt
bun sse/extract.ts --vol 1
```

Создайте папку `sse/text/` перед запуском. Результаты пишутся в `sse/vols/1/` и `sse/drafts/`. Колонтитулы дают опорные номера столбцов. Между опорами номера оцениваются, поэтому особого внимания требуют вклейки, пропуски и страницы с иллюстрациями.
