# Задание на подготовку викитекста по скану

Используйте этот шаблон для оператора или модели. Передайте скан, текущий викитекст, имена статей из словника и локальные правила шаблонов.

1. Восстанови порядок чтения столбцов по скану. Передавай слова, орфографию, пунктуацию и числа печатного источника.
2. Сохрани служебную шапку, подвал и уровень вычитки исходной страницы. Исправляй тело страницы, отмечай неразборчивые места и расхождения с OCR.
3. Для статей с однозначным сопоставлением со словником поставь `<section begin="имя"/>` в начале статьи и `<section end="имя"/>` в её конце. Если статья переходит на соседнюю страницу, укажи соответствующую границу там, где текст действительно начинается или заканчивается.
4. Проверь имена, даты, номера, переносы через границы столбцов и подписи к иллюстрациям. Отдельно пометь каждое место, требующее решения оператора.
5. Верни полный викитекст в `model/N.wiki` и заметку для ключа `N` в [`notes.json`](formats.md#заметки-к-страницам). Начинай строку заметки с `⚠`, когда оператор должен проверить место по скану.
